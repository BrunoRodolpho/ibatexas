W7-O1 — `ibx kernel defer resume <sessionId>` CLI — Tier-1 readiness gap closed
================================================================================

Finding (W6 operational drill, Drill 5, verdict FAIL — top dead-end #1):

  Stuck DEFER recovery: no `ibx kernel defer resume` exists. Operator must
  SCAN Redis, parse JSON, manually publish NATS. Or restart the worker and
  hope `runRecoveryScan` clears it.

Resolution: new CLI subcommand that publishes a synthesised
`payment.status_changed` NATS event so the live `defer-resolver`
subscriber resumes the parked envelope via the standard two-phase commit.

Design rationale: see W7-DECISIONS-ops.md §O1. The CLI is a resolver-kicker,
not a resume-reimplementation; this keeps the recovery logic in one place
(the live subscriber).
