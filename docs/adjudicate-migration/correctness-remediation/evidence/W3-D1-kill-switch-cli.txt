Pub/sub propagation
-------------------
Channel: `development:kill-switch:events` (env-prefixed via rk())
Payload (enable):
  {"action":"enable","scope":"global","enabledBy":"cli:user@host",
   "reason":"<text>","at":"2026-05-23T20:33:39.521Z"}
Payload (disable):
  {"action":"disable","scope":"global","enabledBy":"cli:user@host",
   "reason":"<text>","at":"2026-05-23T20:33:39.521Z"}

API replicas subscribe to this channel for ~100ms propagation (per
docs/adjudicate-migration/migration/05-kill-switch-strategy.md
§"Distributed propagation"). The flag itself is the canonical state;
the pub/sub is best-effort notification on top.
