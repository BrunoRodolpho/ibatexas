Bypass-detection effect
-----------------------
The TypeScript type system now structurally prevents callers from
reaching the bare-arg surface. A new PR that tries to write
`orderCmdSvc.transitionStatus(...)` fails at compile time:

  Property 'transitionStatus' does not exist on type 'OrderCommandService'.

This is the "structural chokepoint" the audit recommended — bypass-
detection is no longer required to police these specific methods (NEW-
P0-X9 still closes the multi-line scan gap for medusaStore / similar).

Caveat
------
The legacy bare-arg test files (packages/domain/src/__tests__/
order-command.service.test.ts and payment-command.service.test.ts)
were rewritten to use the envelope-typed surface. They formerly
exercised the deprecated bare-arg methods directly; coverage of the
underlying executor logic is preserved through the envelope path.
