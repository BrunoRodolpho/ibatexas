NEW-P0-X2 — runCustomerIntent default-EXECUTE for non-enforce kinds (BEFORE)
=============================================================================

Source: deep-audit/01-architecture-coupling.md §G + 05-hidden-bugs.md
Location: apps/api/src/routes/__shared__/customer-intent-gateway.ts:188-208

Symptom
-------
The pure-legacy branch of `runCustomerIntent` (the customer-route adjudicate
chokepoint) hardcoded `decision = { kind: "EXECUTE", basis: [] }`
when the intent kind was:

  - NOT in `process.env.IBX_KERNEL_ENFORCE`
  - NOT in `process.env.IBX_KERNEL_SHADOW`
  - NOT in the `ALWAYS_ENFORCE` set

The `ALWAYS_ENFORCE` set contained ONLY:
  - `customer.anonymize`
  - `customer.anonymize.cancel`

This inverted the documented default-deny invariant from
`governance/04-decision-policy.md`. Every other customer-mutation kind
(profile update, preferences update, PIX details save, order amend,
type switch, address change, …) ran as legacy EXECUTE — the kernel
decision was discarded — UNTIL an operator manually added the kind to
`IBX_KERNEL_ENFORCE` or `IBX_KERNEL_SHADOW`.

Pre-fix code (lines 173-208):
-----------------------------

    const ALWAYS_ENFORCE: ReadonlySet<string> = new Set([
      "customer.anonymize",
      "customer.anonymize.cancel",
    ]);

    let decision: Decision;
    let isPureLegacy = false;

    if (ALWAYS_ENFORCE.has(intentKind) || isEnforced(intentKind, process.env)) {
      decision = adjudicate(envelope, state, policy);
    } else if (isShadowed(intentKind, process.env)) {
      try { adjudicate(envelope, state, policy); } catch { /* ignore */ }
      decision = { kind: "EXECUTE", basis: [] };
    } else {
      // Pure-legacy — no kernel involvement.
      decision = { kind: "EXECUTE", basis: [] };   // ← THE BUG
      isPureLegacy = true;
    }
